  世界生成
  它新增 SkyBlock 世界类型：按默认世界生成生物群系和结构边界，但把几乎所有方块清空。所以沙漠仍算沙漠、下界要塞仍有边界、
  烈焰人仍能在要塞生成，只是地形没了。保留下来的主要是出生小岛、末地传送门框架、试炼刷怪笼/宝库、远古城市传送门框架、蠹
  虫刷怪笼等。见 docs/en_us/generation.md:3。

  主要资源获取链

  - Lava：村民英雄效果下，盔甲匠/武器匠/工具匠可赠送熔岩桶；代码里还有可选规则让流浪商人用 bucket + 16 emeralds 换熔岩
    桶。
  -- Sand / Red Sand：死珊瑚或死珊瑚扇被水流冲刷时，每 16-32 秒生成沙子物品；fire coral 版本给红沙，珊瑚有 3% 概率损坏。
  -- Netherrack / Nylium：在虚空里生成下界门时，周围补少量下界岩或对应群系的绯红/诡异菌岩。
  -- Deepslate：用浓稠药水右键/发射到石头上转化；喷溅/滞留浓稠药水也可批量转化。
  -- Budding Amethyst：中心熔岩，外圈方解石，再外圈平滑玄武岩；随机刻后中心熔岩有概率变成紫水晶母岩。
  -- Diamonds：掉落的铁砧把一组煤炭块压成钻石。
  -- Nether Wart：山羊冲撞下界疣块时，把它打散成下界疣。
  -- Heart of the Sea：给海豚喂鱼后，它可在海洋群系海底的沙/沙砾中挖出海洋之心。
  -- Glow Lichen：闪电击中带藤蔓的荧石，藤蔓变发光地衣。
  -- Chorus Fruit / Chorus Flower：末地折跃门在虚空生成末地石岛时，岛上带紫颂树。
  -- Shulker：再次击杀末影龙时，在基岩柱上生成潜影贝。
  - Dragon Head：被高压苦力怕杀死的末影龙掉龙首。
  - Echo Shard：蝙蝠或海豚被监守者音波攻击杀死时掉回响碎片。
  - Allay：给恼鬼播放正确的 5 个音符序列，可把恼鬼转成悦灵。
  - Sweet Berries：狐狸生成时，如果本来会带物品，有 20% 概率带甜浆果。
  - Dead Bush / Bush：树苗可种在沙/红沙上并枯死成枯萎的灌木；水瓶可把枯萎的灌木变成普通灌木。
  - Mycelium：巨型蘑菇生长时像巨型云杉铺灰化土一样扩散菌丝。
  - Swift Sneak：附魔台附近有监守者时，允许刷出迅捷潜行。
  - Sniffer：溺尸有 1% 概率副手带嗅探兽蛋；它拆海龟蛋时会把嗅探兽蛋放下。
  - Suspicious Sand/Gravel / archaeology loot：嗅探兽在指定结构边界内挖沙/沙砾时，可把方块变成带考古 loot table 的可疑
    沙/可疑沙砾；也可产铁粒。
  - Small Dripleaf / Coral：小垂滴叶可在特定水/黏土/光照条件下扩散；方解石附近若有足够珊瑚块，会随机转成珊瑚块。
  - Creaking Heart：苍白橡树树苗在苍白花园、附近有开放眼眸花时，长树有概率生成嘎枝之心。
  - Breeze：烈焰人从下界跨维度到主世界时可变成旋风人；也能用旋风棒激活未激活的试炼刷怪笼为旋风人刷怪笼。

  数据包加的配方/掉落
  内置 skyblock datapack 还改了不少 loot table 和 recipe：

  - 矿石可合成：基础石材/下界岩/深板岩加对应材料，合成煤、铁、铜、金、红石、青金石、钻石、绿宝石、下界金、下界石英等矿
    石。
  - 方解石/凝灰岩：闪长岩烧炼成方解石，安山岩烧炼成凝灰岩。
  - 发光浆果：甜浆果 + 发光墨囊合成。
  - 马铠/鹦鹉螺铠甲：铜/铁/金/钻石版本可合成。
  - 下界合金升级模板：用下界合金锭替代模板来合成模板。
  - 鞘翅：玩家击杀同时有缓降和漂浮效果的末影螨时有概率掉。
  - 远古残骸：堡垒里的猪灵蛮兵有概率掉。
  - 蜘蛛骑士：玩家杀死蜘蛛骑士其中一半时掉蛛网。
  - 丛林钓鱼：可钓到可可豆。
  - 猫晨礼：稀有给附魔金苹果。
  - 猪灵交易：稀有给镶金黑石。
  - 苦力怕唱片：在堡垒/要塞/远古城市/试炼密室等结构里被骷髅杀死时，掉对应结构限定唱片或碎片。
  - 僵尸疣猪兽：玩家击杀必掉猪鼻旗帜图案。
  - 盛开的杜鹃树叶：有概率掉孢子花，受时运影响。
  - 末影人：可搬高草和大型蕨，杀死后可取回，近似恢复旧版本行为。
  - 试炼宝库：loot table 被重平衡，移除一些会跳过 progression 的强力物品，加入部分陶片和唱片。
